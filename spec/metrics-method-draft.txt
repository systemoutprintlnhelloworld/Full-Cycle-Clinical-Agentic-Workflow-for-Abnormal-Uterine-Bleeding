# 方法与评测指标实现

## 数据与样本
### 多中心病例与样本规模
本研究基于佛山、武汉与新疆三地多中心真实脱敏妇科病例构建评测集，总计 304 例。病例覆盖门诊、入院、手术与康复随访等关键环节，能够在统一流程下对不同模型的临床决策能力进行可比评估。

### 数据来源与结构化字段
评测严格依赖结构化字段。Doc Agent 输出来自各中心模型的 Parsed 解析表，Judge Agent 输出来自 Judge_Parsed 解析表，GT 由标准化对照表提供。原始对话与原始 JSON 仅用于解析修订与异常定位，不直接进入指标计算，以降低噪声并保持计算的可追溯性与可复现性。

### 字段规范化与解析修订
针对跨中心字段漂移、异常列与乱码键值进行统一规范化，确保字段名与语义一一对应。对门诊决策阶段出现修正诊断与治疗方案、但缺乏初步诊断与检查建议的特殊输出，统一迁移为入院决策口径处理，以避免阶段错配导致的评估偏差。所有修订均保留原始记录与修订记录，便于后续复核与审计。

## 流程定义与状态审计
### 全流程节点与 Gate 口径
流程覆盖门诊循环、门诊决策、入院循环、入院决策、手术决策与康复随访六个阶段，并设置 Gate1 与 Gate2 判断是否进入下一阶段。流程通过率依据状态审计结果计算，而非仅依赖裁判评分，以刻画模型在真实流程约束下的推进能力。

### 状态一致性与剔除规则
评测过程中对各阶段状态进行一致性审计，严格区分未经过、终止于某环节与顺利通过。仅对实际产生输出的阶段计入指标，流程提前终止的阶段不计入失败，避免将状态噪声误判为模型缺陷。

## 指标体系与计算口径
### 算法指标
算法指标用于刻画检查对齐与交互效率。检查匹配率依据裁判结构化输出的匹配与未匹配检查计算，分别在门诊与入院循环阶段输出病例均值与总体比例。无效循环率以匹配数量为零的轮次比例衡量低效或偏离的请求。流程通过率由状态审计结果给出 Gate1 与 Gate2 的推进能力。

### Judge 评分指标
Judge 评分用于刻画质量与安全性维度，包括 Gate 继续评测判定、诊断与检查匹配评分、修正诊断与手术方案评分，以及 D3 与 D4 阶段的综合评分。该指标作为算法指标补充，用于衡量关键关口的安全性与临床可行性。

### LLM 语义指标
语义指标以统一 Rubric 驱动 LLM 裁判输出结构化 JSON 证据，覆盖诊断 TopK 语义命中、诊断质量、未匹配检查合理性、推理证据链质量、事实一致性与信息丢失、方案质量、诊断偏向性与康复随访质量。语义评测与算法指标共享一致的流程约束与上下文输入，以保证阶段可比性。

## LLM 评测执行与质量控制
### 提示词与结构化输出
LLM 裁判采用结构化提示词强制输出 JSON 证据，包括匹配对、缺失项、冗余项与评分理由。诊断偏向性明确要求非完全一致时不得给出中立判断，以避免掩盖方向性偏差。

### 采样与可复现性
语义评测在中心与模型内部采用固定采样与稳定哈希策略，确保结果可复现并控制成本。针对不同指标采用分层采样，以覆盖核心病例并维持跨模型可比性。

### 错误处理与人工复核
评测过程对解析异常与可疑字段进行自动标注，并提供人工复核入口。对于裁判输出缺失或格式异常，采用重试与记录机制，确保结果可追溯且可复查。

## 医生评测
### 评分来源与维度
医生评测采用黄医生最新提交的武汉与新疆两中心评分结果，评分维度包括推理合理性与结果质量，覆盖门诊 A、门诊 B、住院 A、住院 B、术后与康复六个阶段。

### 覆盖率审计与缺失处理
对每个病例与阶段进行评分覆盖率审计，要求在阶段实际发生时提供两类评分。缺失评分被记录为待补项，不做数值填补，并在后续统计中与自动指标并行呈现，以保障外部效度评估的透明性。

## 统计汇总与可视化
### 汇总与对比
指标在中心与模型维度聚合输出，形成算法指标与语义指标的联合视图，用于模型间对比与阶段性诊断。

### 可视化与后续分析
结果通过流程漏斗、检查对齐与无效循环的阶段对比、事实一致性热区与诊断偏向矩阵呈现，以支持错误级联与风险路径分析，并为后续可视化与临床解读提供结构化依据。
