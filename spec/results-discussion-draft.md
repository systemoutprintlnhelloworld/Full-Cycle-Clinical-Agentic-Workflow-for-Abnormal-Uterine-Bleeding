# 结果与讨论

## 总体表现概述
整体来看，模型在流程推进层面的差异相对有限，但在信息对齐、诊断覆盖与后续阶段质量上呈现显著分化。综合检查匹配、循环效率、诊断覆盖与 D3、D4 阶段评分等指标，gpt-5-2025-08-07 与 gemini-2.5-pro 的整体表现更为稳定，claude-opus-4-1-20250805-thinking 在门诊阶段具备优势但入院阶段明显回落，deepseek-v3-1-think-250821 与 grok-4 在检查对齐与循环效率方面整体偏弱。

## 检查对齐与循环效率
门诊阶段的检查匹配率整体差异有限，但入院阶段差距扩大。gemini-2.5-pro 在入院阶段的检查对齐更稳定，gpt-5-2025-08-07 在无效循环控制上更优，显示其更能提出有信息增益的检查请求。deepseek-v3-1-think-250821 与 grok-4 在入院阶段的低效轮次比例更高，提示其检查策略在高约束场景下仍存在不足。

## 诊断覆盖与诊断质量
在 D1 诊断 TopK 语义命中上，gpt-5-2025-08-07 的 Top1 命中更稳定，体现出较强的单一诊断收敛能力。gemini-2.5-pro 与 claude-opus-4-1-20250805-thinking 的覆盖更依赖候选扩展，Top5 命中虽接近饱和，但 Top1 仍偏低。grok-4 与 deepseek-v3-1-think-250821 的诊断覆盖整体偏弱，说明其在初诊阶段的核心判断一致性不足。

## 关口与后续阶段质量
Gate2 的通过率总体保持较高水平，但模型间仍存在稳定性差异。进入 D3 与 D4 阶段后，gpt-5-2025-08-07 在方案质量与随访质量上持续领先，gemini-2.5-pro 紧随其后，grok-4 明显落后，表明后续阶段的高质量输出更依赖整体推理稳定性而非单一诊断覆盖。

## 推理一致性与事实可靠性
语义指标显示事实一致性与信息丢失是跨模型的共同短板，且在入院阶段尤为突出。模型更容易在跨阶段叙事中出现事实漂移与关键细节遗漏，这一缺陷与 D2 阶段检查对齐下降和无效循环上升形成呼应，提示入院阶段是质量与安全性的关键瓶颈。

## 医生评测结果
医生评分整体处于较高水平，推理合理性与结果质量普遍在 4.4 至 4.9 区间。门诊 A 的评分相对偏低，住院 B 次之，其余阶段集中在更高区间，显示总体临床可接受度较高但入院阶段仍存在改进空间。覆盖率审计显示少量缺失评分已被标注为待补项，整体趋势判断不受影响。

## 讨论
结果表明入院阶段是性能拐点，检查对齐下降与无效循环上升共同指向信息获取策略不足。诊断覆盖与后续阶段评分的分化说明单一指标无法完整刻画模型能力，需要以流程约束与语义质量指标形成联合评估。gpt-5-2025-08-07 在诊断覆盖与后续阶段评分上具备优势，gemini-2.5-pro 在检查对齐与循环效率上更稳健，claude-opus-4-1-20250805-thinking 在门诊阶段表现突出但入院阶段回落，deepseek-v3-1-think-250821 与 grok-4 在多项核心指标上处于相对弱势。医生评测的阶段性差异与自动指标总体一致，进一步凸显入院阶段的关键性。

## 局限与展望
语义评测仍基于小规模采样且各模型覆盖病例数不完全一致，结论应被视为阶段性结果。医生评测目前仅有单名专家的最新评分，尚不足以形成稳定的一致性证据。未来工作将优先强化入院阶段的信息对齐与事实一致性验证，扩展语义评测样本规模，并引入多名专家评分以提高结论的稳健性与外部效度。
