# 方法与评测指标实现

## 指标体系与数据来源
本研究建立覆盖门诊、入院、手术与康复随访的全流程评测体系，采用算法指标与 LLM-as-Judge 语义指标并行的混合框架。指标计算仅基于结构化字段完成，Doc Agent 输出取自各中心模型的 Parsed 解析表，Judge Agent 输出取自 Judge_Parsed 解析表，GT 取自已标准化的对照表。该设计避免直接读取原始对话或原始 JSON 的噪声，确保字段可追溯与可复现，并降低跨中心格式差异对指标的影响。

## 流程状态与纳入规则
评测以流程状态为核心约束，严格区分“未经过”“终止于某环节”与“顺利通过”，仅对已实际产生输出的阶段计入对应指标。对于少量在门诊决策阶段出现“修正诊断与治疗方案”而缺乏初步诊断与检查建议的特殊输出，研究将其视为 D2 性质的决策并进行迁移处理，D1 决策标记为特殊终止而不计入 D1 决策评估，D2 决策沿用入院阶段的评价口径。该规则保证流程一致性与指标含义的稳定性。

## 算法指标
算法指标用于刻画流程对齐与阶段推进能力。检查匹配率以裁判结构化输出的匹配与未匹配检查为依据，分别在门诊与入院循环阶段计算病例均值与总体匹配比例，反映模型与真实执行检查的对齐程度。无效循环率定义为交互轮次中匹配数量为零的比例，用于衡量信息增益不足的重复或偏离请求。流程通过率以流程状态为准，衡量 Gate1 与 Gate2 的推进能力，而非依赖裁判评分。与此同时，Judge 评分与通过率作为安全性与质量的补充证据，覆盖 Gate1 与 Gate2 的继续评测判定，以及 D3 与 D4 阶段的综合评分与子项评分。

## LLM-as-Judge 语义指标
语义指标以统一 Rubric 驱动 LLM 裁判输出结构化 JSON 证据，覆盖诊断、检查、方案与推理质量。诊断 TopK 语义命中用于衡量 D1 初步诊断对 GT 诊断集合的覆盖能力，兼顾多对多语义匹配。诊断质量在 D1、D2、D3 阶段评估准确性、合理性与逻辑性，并给出匹配对、缺失项与冗余项。未匹配检查合理性关注模型提出但未执行的检查是否仍具临床意义或存在冗余。推理证据链质量评估关键事实覆盖与证据闭环程度。事实一致性与信息丢失用于衡量患者信息汇总与诊疗经过回顾对 GT 事实的忠实度，记录冲突与遗漏。方案质量分别针对入院初步治疗方案与术后方案，评价准确性、安全性、完备性与综合得分。诊断偏向性在 D3 阶段给出相对 GT 的方向与严重度，并要求非完全一致时不输出中立判断。康复与随访计划在 D4 阶段评估完整性、合理性与风险点覆盖。

## 采样策略与输出产物
LLM 语义评测采用中心与模型内固定采样策略，以稳定哈希保证可复现性，从而实现跨模型可比。由于不同模型覆盖病例的交集有限，实际样本量会随模型而变化。主要结果输出包含算法与 Judge 评分汇总表、LLM 语义指标细表以及指标字段映射规范文档，形成从字段到指标的可追溯链路。

## 数据聚合与可视化计划
指标聚合流程将 Doc、Judge 与 GT 字段统一映射后进行状态审计与指标计算，并将未经过或提前终止的阶段从计算中剔除，避免将流程终止误判为失败。可视化呈现将聚焦流程漏斗、生存率与关口拦截位置，检查匹配与无效循环的阶段对比，诊断偏向与事实一致性的中心与模型差异，以及病例级随轮次信息增益的变化轨迹。

## 医生评测
当前医生评测已纳入单名专家的最新评分结果，后续将补充其余医生的独立评分以完善一致性与外部效度分析。
